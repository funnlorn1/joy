# Territory Rush — 2D

Браузерная игра про захват территории в духе Paper.io. Это самостоятельный проект с оригинальным названием и графикой.

## Возможности
- Чистая 2D-графика, без 3D и онлайн-режима.
- Большая карта 180×120 клеток.
- Камера плавно следует за игроком.
- 10 ботов-соперников.
- Девять процедурно очерченных стран: захватывай клетки страны, чтобы заполнить её на 100%.
- Захват замкнутой области, уязвимый след, таблица лидеров.
- Рекорд хранится локально в браузере.
- WASD / стрелки и сенсорные кнопки.

## Запуск
Открой `index.html` через VS Code Live Server или любой локальный статический сервер.

## GitHub Pages
Загрузи содержимое проекта в репозиторий. Открой **Settings → Pages → Deploy from a branch**, выбери `main` и `/ (root)`. Нажми Save. Проект не требует сборки.
